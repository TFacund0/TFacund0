## Proyectos

**Clinicks Desktop** — Sistema de gestión hospitalaria de escritorio (pacientes, turnos, admisiones, infraestructura, analítica) con control de acceso por rol. Arquitectura N-Layer, Entity Framework 6, SQL Server. 74 tests (MSTest + Moq) validados en CI en cada commit.
[Ver repositorio →](https://github.com/TFacund0/Clinicks-Desktop)

**Clinicks Web** — Versión web de Clinicks, con alcance acotado al rol del médico: agenda de turnos, consultas, documentación de procedimientos e historial clínico en tiempo real. .NET 8, ASP.NET Core, React, PostgreSQL, Tailwind CSS. 49 tests unitarios (xUnit + Moq) con CI en GitHub Actions.
[Ver repositorio →](https://github.com/TFacund0/Clinicks-Web)

**CVA Muebles (E-commerce)** — Plataforma web híbrida (e-commerce/showroom) para un taller de carpintería, desarrollada en PHP con CodeIgniter 4, capa de servicios y seguridad alineada a OWASP Top 10.
[Ver repositorio →](https://github.com/TFacund0/CVA-Muebles)

**DroneScript** — DSL y compilador (parser LL(1) recursivo descendente) para planificar y simular misiones de drones. TypeScript, React, Vite, 94% cobertura de tests.
[Ver repositorio →](https://github.com/TFacund0/DroneScript) · [Demo →](https://drone-script.vercel.app)
